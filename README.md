# 🍽️ Food Ordering Behaviour and Consumer Trends: A Structured Analysis of Choices and Habits

## 📌 Project Overview

The **Food Ordering Behaviour and Consumer Trends** project is an interactive **Tableau dashboard** developed to analyze customer ordering patterns, revenue generation, delivery performance, and customer preferences in the food delivery industry.

Using Tableau's visualization capabilities, this project transforms raw food ordering data into meaningful insights that help businesses understand customer behavior, improve operational efficiency, and make data-driven decisions.

---

## 🎯 Project Objectives

- Analyze customer ordering behavior across different cities.
- Identify the most popular cuisines and meal types.
- Measure business performance using Key Performance Indicators (KPIs).
- Analyze delivery performance and customer satisfaction.
- Study repeat customer behavior.
- Develop an interactive dashboard for business intelligence.

---

## 📂 Dataset Information

The dataset contains **50,000 food orders** and includes the following attributes:

- Order ID
- City
- Cuisine
- Meal Type
- Restaurant Type
- Order Value
- Delivery Fee
- Rating Given
- Time Taken To Order
- Repeat Order Status
